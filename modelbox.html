Modelo em Caixa, model box HTML

Os elementos html são estruturados em um modelo denominado modelbox, que refere-se a caracteristica de um elemento pode conter outros elementos, sendo que cada um possui uma estrutura interna, similar a ideia e uma caixa dentro da outra.

Estrutura de um elemento HTML

Todos elementos HTML possuem conteúdo, padding, bord, offset. Sendo a religião de conteúdo estruturada em três camadas 1) background-color 2) background-image 3) -Content
